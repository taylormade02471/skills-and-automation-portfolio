# Wasteland Survivor

## Proof of work

Wasteland Survivor is a browser based survival game prototype with an offline guest path, lobby flow, match room, loadout state, combat HUD, input handling, wave state, progression, replay surfaces, and installable PWA structure. The repository also contains the broader multiplayer, backend, storage adapter, and testing work; external production services remain separately gated.

The attached proof clip shows a real local browser run reaching the final loadout room and the playable survival interface. The run was checked with Playwright and recorded without unrelated desktop content. The browser console reported zero errors during the verification pass.

## Verification scope

- Offline guest onboarding and lobby path
- Solo Survival selection
- Match room and final loadout
- Ready for Nightfall transition
- Combat HUD with health, shield, ammunition, dash, wave, and objective state
- Local browser smoke verification

This is a prototype verification, not a claim of production uptime, revenue, or independently verified external multiplayer services.
