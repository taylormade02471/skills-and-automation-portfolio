## Evidence rules

- A repository proves authorship context, not that the software is production-ready.
- A live deployment proves that a public build loads, not that every backend integration is connected.
- A test count proves the named test run only; it does not prove a different project’s test count.
- A screen recording must show a continuous run of the work itself. A recording of the Reworkio skills page shows profile state, not the underlying skill.
- ROI must be measured from a before-and-after run or labeled as an estimate. No unmeasured savings or revenue claim belongs in a proof submission.
